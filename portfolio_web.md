
Act as a senior full-stack developer, UI/UX designer, and data analyst.

Create a futuristic, highly interactive portfolio website for a Data Analyst.

GOAL:
- Target audience: Recruiters, HR, startup founders, tech managers, freelance clients
- Objective: Get hired, showcase projects, and attract freelance work

THEME:
- The website should feel like a "Data Analytics Dashboard / Command Center"
- Not a traditional portfolio — it should immediately look like a data-focused interface

STYLE:
- Futuristic, clean, minimal but interactive
- Primary color: White with subtle accents (light blue / neon tones optional)
- Smooth animations (not heavy, performance optimized)
- Fast loading is critical

HOMEPAGE:
- Dashboard-style layout
- Include:
  - KPI cards (projects, datasets, tools, experience)
  - Interactive charts (use sample + real data feel)
  - “Recent Insights” section (blog preview)
  - Featured projects as data reports (not simple cards)
- Add micro-interactions (hover, click, transitions)

ABOUT PAGE:
- Short professional bio
- Skills overview (SQL, Python, Excel, Power BI)
- Career focus: Data Analyst

PROJECTS PAGE:
- Display projects as case studies
- Each project must include:
  - Problem statement
  - Dataset source (Kaggle)
  - Tools used
  - Process explanation
  - Key insights
  - Embedded Power BI dashboard
  - GitHub link
  - “View Case Study” and “Download Report” buttons

SKILLS PAGE:
- Visual representation (charts, bars, icons)
- Group skills: Tools, Programming, Analytics

RESUME PAGE:
- Download button
- Clean preview

BLOG PAGE:
- Articles related to data analysis, SQL tips, insights

CONTACT PAGE:
- Simple form + email
- Social links (LinkedIn, GitHub, etc.)

SPECIAL FEATURES:
- Add subtle “data-like” interactions (hover reveals insights, click = drill-down feel)
- Use charts and data visuals across the site
- Maintain fast performance (optimize scripts, lazy load heavy elements)

TECH:
- Use HTML, CSS (Tailwind), JavaScript (or React if needed)
- Use Chart.js or D3.js for charts
- Optimize for GitHub Pages deployment

OUTPUT:
- Provide full website structure
- Clean, modular code
- Ensure responsiveness (mobile + desktop)
